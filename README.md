# 基于 LangChain React Agent 的电商智能客服系统

## 项目简介
基于 LangChain React Agent 构建具备多轮对话记忆、工具调用、情绪识别能力的电商AI客服智能体。
完整覆盖 FAQ 问答、本地订单数据库查询、退换货业务咨询、用户负面情绪安抚、复杂问题自动转接人工客服全业务流程，模拟企业可落地级客服系统。

## 技术栈
Python、LangChain、React Agent、ChatOpenAI、SQLite、ConversationBufferMemory、关键词文本匹配

## 核心功能
1. 多轮对话记忆：使用 ConversationBufferMemory 存储上下文，实现连贯连续对话
2. 本地订单数据库：SQLite 持久化订单数据，封装独立查询工具，约束模型不编造虚假业务数据
3. 多工具协同调度：订单查询工具、FAQ知识库检索工具、用户情绪识别工具
4. 负面情绪自动安抚：识别消极词汇优先安抚用户情绪，提升客服体验
5. 异常兜底分流：限制 Agent 最大迭代次数，模型解析异常、复杂问题自动引导人工客服
6. AI+人工闭环：无法处理的问题统一提示转接人工，贴合真实电商业务场景
